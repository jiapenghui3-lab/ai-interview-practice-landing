# 模拟面试复盘标准 v1

## 评分原则

- 总分 100 分，只依据候选人在本次面试中的原话与可核验证据。
- 每项结论必须标记为“已证明”“部分证明”或“未证明”。
- 不因表达自信而推定经历真实，不把团队成果自动算作个人贡献。
- 报告只给一个下一轮优先练习重点，避免一次堆叠过多建议。

## 六个维度

1. 业务问题转化 AI 产品方案（20 分）：问题、方案选择、取舍和业务目标是否清楚。
2. 用户调研与需求分析（15 分）：是否说明方法、样本、发现和优先级依据。
3. 跨团队协作与推进（15 分）：是否说明个人职责、关键决策、冲突与推进动作。
4. 数据验证与效果评估（20 分）：是否说明指标口径、周期、样本、对照和结果。
5. 大模型能力边界与风险（15 分）：是否识别模型限制、失败模式和兜底机制。
6. 复盘与迭代思维（15 分）：是否准确归因并提出可执行改进。

## DeepSeek V4 Flash 样例验收

- 模拟数据服务端调用成功，模型返回可解析 JSON。
- 第一次完整样例综合分 48，证据等级为“部分证明”。
- 模型准确识别出 30% 提升缺少统计周期、用户调研缺少样本、个人推进证据不足。
- 下一轮重点被收敛为数据验证框架，而不是同时给出多项泛化建议。
